# Python Mini Challenges

## Objective
Short practice problems to build logic, loop usage, and confidence with Python's core data types: strings, lists, and dictionaries.

## Challenges Solved

| File | Problems |
|---|---|
| `strings.py` | Reverse a string, count vowels, check for a palindrome |
| `lists.py` | Find largest and smallest, remove duplicates, find common elements |
| `dictionaries.py` | Character frequency, merge two dictionaries, find the key with the maximum value (plus average marks) |

## Technologies Used
- Python 3 (no external libraries)

## Folder Structure
```
python-mini-challenges/
├── strings.py
├── lists.py
├── dictionaries.py
├── .gitignore
└── README.md
```

## How to Run
Open a terminal in this folder and run each file:
```
python strings.py
python lists.py
python dictionaries.py
```
